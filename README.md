# Guts and Glory (web port)

Unofficial browser port of **Guts and Glory** by HakJak, ported by Down1oads. Not affiliated with the original developers. Buy the real game on Steam.

Play: https://down1oads.github.io/gutsweb/

- Every level is a separate download that loads when you pick it, so the first load only fetches the menu (about 160 MB).
- Controls: arrow keys drive and steer, W/S/A/D lean, Space handbrake, Shift boost, V respawn at checkpoint, N restart level, Z lights, C slow motion, Esc pause.
- Needs a desktop browser with WebGL 2.
